# Mini Data-Analysis: Deliverable 1

## Overview

This repository contains my Mini Data-Analysis. The analysis uses the Boulder residential sales dataset and the NYC squirrel census dataset for the initial exploration. The Boulder housing dataset was selected for the main analysis.

## Files

* `MiniDataAnalysis1.qmd` contains the analysis, code, research questions, and results.
* `boulder-2020-residential_sales.csv` contains the Boulder residential sales data.
* `squirrel-data.csv` contains the squirrel census data.
* `README.md` provides information about the project and its contents.

## Analysis

The main analysis investigates the relationship between the number of bedrooms and the sale price of residential properties in the Boulder housing dataset. It also considers whether this relationship differs between residential properties and residential condominiums.
